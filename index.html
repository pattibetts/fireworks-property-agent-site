Fireworks Property Agent

A personal automation that turns booking-confirmation emails into a tidy reservation calendar.

This project watches one person's Gmail inbox for booking confirmation emails from a handful of home-exchange and hospitality platforms (Kindred, HomeExchange, People Like Us), extracts the guest, dates, and status, and logs each booking as a row in a private Google Sheet.

What it does

  • Reads new, unlabeled booking emails in one Gmail inbox
  • Labels each email "Processed" once it's been recorded
  • Extracts structured booking details using an AI model
  • Writes the result to a Google Sheet only the owner can access
